# 001. マイサイズ在庫切れ時の「似ている在庫あり商品」提案

- ステータス: 💡 アイデア
- 追加日: 2026-10-21
- 参考: アパレル EC の「カートに追加」モーダル（サイズ別在庫表示＋「サイズ在庫のある似たアイテム」）

## 概要

ユーザーが自分のサイズ（例: **M**）を登録しておくと、ほしい商品がそのサイズで在庫切れだったときに、
**似ている商品のうち M の在庫があるもの** を自動で提案する。

## 解決したい課題

- 欲しい商品が自分のサイズだけ SOLD OUT → そのまま離脱してしまう
- 参考事例は「サイズ在庫のある似たアイテム」を出しているが、**どのサイズの在庫があるかは商品ごとにバラバラ**。
  自分のサイズ（M）が在庫ありかどうかは、提案商品を開くまで分からない
- → 「自分のサイズ基準」で絞り込んで出せば、提案からそのまま購入につながりやすい

## 体験イメージ

1. 初回またはマイページで「いつものサイズ」を登録（例: トップス M）
   - 未ログインでもブラウザに保存しておく（localStorage など）
2. 商品ページ / カート追加モーダルで、マイサイズを最初からハイライト表示
3. マイサイズが在庫切れの場合:
   - 「M は在庫切れです」＋ 再入荷通知ボタン
   - その下に **「M の在庫がある似たアイテム」** をカルーセル表示
   - 各カードに「M 在庫あり」バッジ、ワンタップで M をカートへ
4. マイサイズは在庫ありなら、通常どおり M を選択済み状態にする

## 「似ている」の判定案

優先度順にスコアリングして並べる:

1. 同じコレクション / 商品タイプ（例: ロングスリーブ T シャツ）
2. 同じカラー系統（WHITE など。バリアントのカラーオプションで判定）
3. 共通タグ（素材・シルエット・テイスト）
4. 価格帯が近い（元商品 ±30% など）
5. 将来的には Shopify の Product Recommendations API（`related` / `complementary`）の結果をベースにする

→ 上記候補の中から **マイサイズのバリアントが `available` のものだけ** を残す。

## 実装メモ（Shopify）

- **候補取得**: Storefront API / `/recommendations/products.json?product_id=...&intent=related`、
  または Liquid で同コレクションの商品を取得
- **在庫判定**: 各商品の `variants` から `option(サイズ) == マイサイズ` かつ `available == true` を確認
  - 在庫数そのものを出したい場合は `inventory_quantity`（公開設定に注意）
- **マイサイズ保存**:
  - ログイン会員 → 顧客メタフィールド（例: `custom.my_size_tops`）
  - 非ログイン → localStorage / Cookie
- **テーマ組み込み**: Dawn 系ならテーマアプリ拡張（App Block）か、商品ページ用セクションとして追加
- カテゴリ別にサイズを持てるようにする（トップス M / ボトムス 30 / 靴 26.5 など）

## 未決事項・メモ

- サイズ表記がブランドごとに違う場合（M / 2 / 38 など）の正規化をどうするか
- 似た商品が 0 件のときの表示（再入荷通知のみ？ 近いサイズ L を提案？）
- 「M は在庫切れ」の判定を商品一覧（コレクションページ）でも出すか
